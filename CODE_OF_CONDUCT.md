# Code of conduct

Gantry is a small project run by one person for people who like playing and modding games. Please keep it a friendly place.

- Be kind. Disagree with ideas, not with people.
- No harassment, insults, slurs or personal attacks, in issues, pull requests, discussions or anywhere the project is talked about.
- Assume the other person is trying to help. Say what you tried and what happened; do not demand.
- Do not post other people's private information, API keys or account details. If you pasted one by mistake, delete it and change the key.
- Do not ask for or share pirated games or cracked software here.

Anyone who breaks these rules can have comments removed or be blocked. To report a problem, use the repository's
private security/abuse contact on GitHub (Report content) or open a discussion and ask a maintainer to look.
