# Accessibility

- Every button, field and list has a name a screen reader can say; windows announce themselves as dialogs.
- A window takes the focus when it opens, keeps Tab inside, and gives the focus back when it closes. Esc closes the top window.
- Things that look like buttons work with Enter and Space.
- Text colours are fitted to each theme (also your own) so muted text, accent text and status colours keep a contrast of at
  least 4.5:1. *Settings → Stronger text and borders* goes further, and *Motion → Off* stops animations.
- The automatic screen test fails when a control has no name or a text is too faint in any theme.
- Interface size goes up to 150 %; every window fits the screen at that size.
