# The mod list

- **Order:** drag the ⠿ grip, or use ▲▼. Mods lower in the list win when two provide the same file.
- **Select:** click a mod's number (Shift-click for a range). The bar above the list offers *Turn on*, *Turn off*,
  *Group…* and *Remove*. Groups are labels; the chips above the list (*Updates*, *Conflicts*, *Off*, one per group) filter
  without changing the order.
- **Undo:** removed mods go to the library trash and an *Undo* toast brings them back. *History…* goes back to any earlier state.
- **Conflict viewer:** when two mods provide the same file the list shows ⚔ and *Open the conflict viewer*. It shows who
  overwrites whom (with file counts), warns about a mod that has no effect because all its files are replaced, lets you make
  one mod win against another in one click, and searches every conflicting file by path or mod name. Clicking a mod name
  pins that single file to it; *Back to the load order* forgets your choices. Pins survive a redeploy.
- **Plugins and load order** (Skyrim SE/VR, Fallout 4, Starfield): the *🔌 Plugins* button on the Tools tab checks headers and missing masters,
  sorts, and writes `plugins.txt`.
- **Back to vanilla** removes every mod file and puts the original files back.
