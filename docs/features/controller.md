# Controller and Steam Deck mode

Start with `rig --deck`, or switch on *Controller mode* in Settings. Controls get bigger and a bar at the bottom shows the
buttons.

| Button | Does |
|---|---|
| D-pad / left stick | move |
| A | select |
| B | back, or close the top window |
| X | play |
| Y | search |
| LB / RB | switch tabs |
| Menu | your games |
| Right stick | scroll |
