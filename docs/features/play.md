# Playing

- **Play** links the mods into the game and starts it. The arrow next to it plays **without mods**, or with a saved
  profile; mods come back when the game closes.
- **Without opening Gantry:** the arrow also has *Create a shortcut for this game*. In a terminal: `rig --play "Schedule I"`,
  `rig --play 3164500 --vanilla`, `rig --play 3164500 --profile "Only fixes"`. A name only has to be unique.
- **Saves** are copied before every launch and after every session (only when they changed). *💾 Save Guard* (Tools tab) lists them
  and restores one; a restore first backs up what is there now.
- **Play time:** the *Activity* tab shows time in the game, crashes, how much you played with mods, the last 14 days, and a
  timeline that mixes sessions with changes to the mod list.
- **Why is it slow?** See [performance](performance.md).
- **Trainers:** the Tools tab starts a trainer together with the game when *Auto Trainer* is on.
